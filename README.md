<table>
<tr>
<td align="center" width="25%">

### 📏 Measure

Measure the system before proposing an optimization.

</td>

<td align="center" width="25%">

### 🔍 Diagnose

Find the actual root cause instead of treating symptoms.

</td>

<td align="center" width="25%">

### 🧩 Simplify

Prefer the smallest maintainable solution that solves the problem.

</td>

<td align="center" width="25%">

</td>
